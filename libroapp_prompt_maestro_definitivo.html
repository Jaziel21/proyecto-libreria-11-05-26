AUTENTICACIÓN Y ROLES Método: Firebase Auth email/contraseña + Google Sign-In Roles: admin · cajero · bodega (campo rol en /empleados/{uid}) Guards: go_router redirect() — verifica AuthState antes de cada ruta Sesión: persistencia automática Firebase + cierre seguro multiplataforma Flujo: splash → check auth → [login | home según rol] Errores: mensajes traducidos al español, retry automático en timeout ## DISEÑO UI/UX — SISTEMA DE DISEÑO Grid: 8pt spacing system Breakpoints: mobile <600 · tablet 600-1024 · desktop >1024 Mobile: BottomNavigationBar + cards + drawers Desktop/Web: NavigationRail/Drawer lateral + DataTable + sidepanels Temas: ThemeData.colorScheme M3 · seedColor personalizado Feedback: SnackBar · AlertDialog · SkeletonLoader · estados vacíos Accesibil.: contraste WCAG AA · semanticLabel · texto dinámico ## REGLAS FIRESTORE (seguridad producción) - Solo usuarios autenticados leen catálogo - Empleado solo modifica recursos de su sucursal - Admin tiene acceso completo - Validación de campos obligatorios en reglas - Rate limiting en escrituras masivas - Índices compuestos en: libros(categoria+precio), ventas(fecha+estado) ## GESTIÓN DE ESTADO — PATRÓN BLoC/Cubit AuthCubit: unauthenticated | loading | authenticated(user,rol) | error InventoryCubit: initial | loading | loaded(List) | searching | empty | error SalesCubit: idle | cartBuilding | processing | completed | error PurchaseCubit: initial | loading | loaded | submitting | error ReportsCubit: initial | loading | loaded(DashboardData) | error Estados explícitos con freezed, transiciones con animaciones suaves. ## MÓDULO MVP PRIORITARIO — Inventario de libros ✓ CRUD completo de libros con imagen (Firebase Storage) ✓ Búsqueda por ISBN, título, autor, categoría (Firestore queries) ✓ Control de stock con alertas de bajo inventario (threshold configurable) ✓ Relaciones libro ↔ autor · libro ↔ categoría ✓ Layout adaptativo: BookCard (móvil) / BookDataTable (desktop/web) ✓ Filtros múltiples + ordenamiento en tiempo real ✓ Soporte offline (Firestore persistence habilitado) ✓ Importación masiva por CSV (Cloud Function) ##
